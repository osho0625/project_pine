# Pine Icons

Place pineapple PWA icons here:

- `pine-icon-192.png` — 192×192 pineapple icon (for manifest + notifications)
- `pine-icon-512.png` — 512×512 pineapple icon (for PWA splash screen)

These icons should be square, with a pineapple (🍍) design on a green (#4a7c47) background.
Recommended: use maskable icon format for best display across platforms.
